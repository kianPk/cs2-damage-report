# CS2 Damage Report

End-of-round **damage report** (`!damage`) for CS2 — hits, damage dealt/taken, and ADR helpers.

Useful on Public / retake servers where players want a quick duel breakdown without a full demo.

## Features

- Per-pair hit / damage tracking
- Optional headshot count via `Add(..., headshot: bool)`
- `Totals()` aggregate damage dealt/taken per player
